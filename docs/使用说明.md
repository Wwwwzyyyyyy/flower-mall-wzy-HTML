# 使用说明

## 用户端

首页提供轮播、场景分类、商品推荐、花语和祝福语入口。通过顶部“鲜花商城”按分类或关键词查询，点商品查看规格、图片、库存与真实购买评价。

1. 使用demo账号体验，或创建4至40位字母/数字/下划线账号，密码至少8位。商家与用户分别登录，权限彼此隔离。
2. 选中商品并加入购物袋。在购物袋修改数量、选择需要结算的商品。缺货或下架商品不能提交。
3. 个人中心的“收货地址”可添加、编辑、删除与设置默认地址。演示地址不用于真实配送。
4. 在AI祝福语页面选择场景、收花人、风格和补充信息，生成后可编辑、复制或“保存并用于订单”。无Key时标明本地模板。
5. 购物袋中确认地址、随花祝福与备注，提交后创建待支付订单。服务端核价、保存收货/商品快照、扣减可售库存。
6. 点击“前往模拟支付”，可模拟成功或失败。成功进入待商家接单；失败可重试。此过程不发生真实扣款。
7. “我的订单”查看制作配送进度；待支付订单可取消。付款后需要通过退款申请处理。
8. 退款可填写部分金额或全额、原因和说明；在个人中心“退款记录”或订单详情查看审核结果、拒绝/失败原因。
9. 已完成订单的商品可评价1至5星、填写文字并上传最多9张实拍图。提交前预览与删除所选图片。个人中心可查看、修改、删除自己的评价，删除后不允许重复评价同一订单明细。
10. 收藏商品可在个人中心浏览，再点商品详情里的“收藏”切换取消。个人中心还可改资料/头像、密码与退出。

## 商家端

入口 `/#/admin`。本地演示账号admin / Admin123!；MySQL正式环境使用初始化时配置的密码。

| 菜单 | 操作 |
|---|---|
| 经营概览 | 今日/月/累计模拟收款、订单、库存预警、近30天趋势、商品排行与评价统计 |
| 商品管理 | 新增/编辑、价格规格、分类、初始库存、预警阈值、上下架和逻辑删除 |
| 图片管理 | 查看上传图片；清理未引用文件。任何商品、历史订单、头像或评价仍引用的图片禁止删除 |
| 库存管理 | 增加、减少或设为实际可售数量；必须填写说明；可筛选预警商品 |
| 库存记录 | 查看下单预留、取消恢复、商家调整等流水及操作前后数量 |
| 订单管理 | 搜索编号、筛选状态、查看商品/地址/祝福快照、接单或拒单 |
| 退款管理 | 同意、拒绝或重试；拒绝需填写原因；同意后由后台模拟退款任务处理 |
| 评价管理 | 看实拍图、按评分/商品筛选、回复、填写依据后隐藏或恢复评价 |
| 账单汇总 | 日期范围内支付成功额、退款成功额与净流入；查看支付记录及关联订单 |
| 用户管理 | 搜索昵称/手机/账号，查看消费、历史订单、禁用或恢复用户 |
| 操作日志 | 查看商品、订单、退款审核、评价处理、用户状态等操作依据 |

商品编辑里的“设封面”会将所选详情图同时作为封面。图片“前移/后移”调整顺序，保存商品后生效。原商品的库存不能通过商品编辑覆盖，必须走库存管理并记录日志。

订单流程：**待支付 → 待商家接单 → 已接单 → 制作中 → 配送中 → 已完成**。操作不能跳过步骤。待接单可拒单，必须填写理由，系统创建退款记录；退款成功后才恢复符合条件的库存。存在待审核/处理中/失败退款时暂时阻止继续履约，以免状态冲突。

用户禁用后旧令牌失效，历史订单和退款保留；恢复后需重新登录。商家不能查看用户密码哈希，也不能直接编辑用户评价正文。
